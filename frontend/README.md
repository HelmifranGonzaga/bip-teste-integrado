# Frontend Angular

Aplicação Angular (standalone) para consumir a API de benefícios.

## Requisitos

- Node.js 20+
- Backend em execução na porta 8082

## Como executar

```bash
npm install
npm start
```

Aplicação disponível em `http://localhost:4200`.

## Qualidade de código

```bash
npm run lint
npm run format
npm test
```

## Funcionalidades

- Listagem de benefícios
- Criação e edição de benefício
- Exclusão de benefício
- Transferência entre benefícios
